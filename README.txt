# 감성 미니멀 웨딩 청첩장

## 실행 방법
1. 압축을 해제합니다.
2. `index.html`을 크롬 또는 엣지에서 엽니다.
3. 인터넷 연결이 있으면 Google Fonts가 적용됩니다. 폰트 연결이 없어도 기본 글꼴로 표시됩니다.

## 파일 구성
- index.html : 페이지 구조와 콘텐츠
- style.css : 반응형 디자인 및 스타일
- script.js : 갤러리 팝업, 계좌번호 복사
- assets/ : 실제 이미지 파일

## 수정할 내용
현재 이름, 날짜, 예식장 주소, 계좌번호는 모두 예시입니다.
`index.html`에서 밤/만쥬, 날짜, 장소, 계좌 정보를 실제 정보로 바꿔주세요.
구글 지도 링크도 실제 예식장 검색 주소로 변경하면 됩니다.

## 참고
첨부 캐릭터 원본을 그대로 사용해 웨딩 장면 이미지로 구성했습니다.
갤러리와 대표 이미지는 외부 이미지 링크가 아닌 assets 폴더의 실제 파일을 사용합니다.
